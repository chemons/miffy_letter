# 一些会走向你的小念头

五幕私人互动情书。原生 HTML、CSS、JavaScript，无构建步骤，无后端、账号、外部字体或运行时依赖。主页面和所有图片均可离线读取。

当前版本在已有五幕页面上更新了完整情书文案与淡粉色主题，保留已有翻幕、展开、选择、重读和分享功能。封面副标题为「写给你，和那些忽然想起你的时刻。」。

## 本地预览

直接双击 `index.html`，在浏览器中打开即可阅读。系统分享和自动复制能力会因浏览器及安全上下文不同而有所区别，始终提供手动复制备用方案。

如已安装 Node.js，也可以在项目目录运行：

```sh
node preview.mjs
```

打开 `http://127.0.0.1:4173`。按 Ctrl+C 停止。服务只监听本机，不向局域网公开。部署只需 `index.html` 和 `assets/`，无需部署预览服务与测试文件。

## 内容与交互

- 五幕在同一页面切换，显示进度，可返回上一幕，长内容自然纵向滚动。
- 第二幕直接显示全文，无强制等待动画。仅保留 0.32 秒的整幕淡入；减少动态效果偏好会关闭它。
- 第三幕为四个原生 `details`，可以独立展开、收起，也可以同时展开。
- 第四幕四个选项可随时更改，回应保留自然段。支持键盘方向键、Home、End。
- 第五幕准确呼应当前选择；未选择则不显示附加回应。
- 「收下这份想念」进入简洁结束状态，不触发下载或写入设备。
- 「再读一遍」回到封面，清空选项、回应、全部展开状态、结束状态和分享提示。
- 「把我的选择寄给他」只在主动点击后尝试系统分享。不支持或失败时尝试复制，复制也不可用时显示可手动选中的文本。取消分享不会显示发送成功，也不会自动复制。
- 选择仅保存在当前页面的 JavaScript 内存中；刷新即重置。没有 localStorage、Cookie、分析统计或上传请求。

## 修改文字

页面文案位于 `index.html` 的五个 `section[data-scene]` 中，每个自然段保留一个 `<p>`。第四幕回应和第五幕呼应统一位于脚本内的 `choices` 对象中，键为 `hug`、`walk`、`quiet`、`food`。正文与按钮建议保持自然段和现有留白层级，不逐句增加视觉强调。

## GitHub Pages 部署

1. 确认图片再发布许可，或替换为已获准素材。
2. 在 GitHub 创建仓库，通过 **Add file → Upload files** 上传 `index.html`、`assets/` 和 README；`index.html` 应位于仓库根目录。也可以使用 Git 提交并推送这几个文件。
3. 打开仓库 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 部署完成后，Pages 页面会给出 `https://用户名.github.io/仓库名/` 格式的地址。按需启用 **Enforce HTTPS**。页面全部使用相对资源路径，适合仓库子路径。
5. 使用该 HTTPS 地址分享。当前未创建远程仓库，也没有实际发布；本地 `127.0.0.1` 地址无法给另一台手机访问。

GitHub 当前部署说明：[Configuring a publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## iPhone、Android 与微信验收

部署后，在 iPhone Safari、Android Chrome，以及从聊天中点开链接的微信内置浏览器分别操作：

1. 从封面连续阅读至结束，检查长文本可滚动、无横向滚动、底部按钮不受安全区域遮挡；收起/展开地址栏并横竖屏切换。
2. 第三幕逐个展开再收起，并同时展开四项，检查图片和文字没有遮挡、段落间距自然。
3. 第四幕连续切换四项，每一项进入第五幕核对呼应，再返回修改；再测试跳过选择直接到结尾。
4. 从完整正文和收好状态分别重读，确认选择与展开全部清空，进度回到 1 / 5。
5. 主动点分享，分别测试正常分享、取消、复制、复制权限拒绝后的手动选择。微信可能不提供 Web Share API，此时走复制或手动文本路径。
6. 在系统开启减少动态效果后重读，检查无非必要动画；放大字体后检查文字和按钮仍可阅读与操作。
